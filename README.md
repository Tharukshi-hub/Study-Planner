## Smart Study Planner with AI Suggestions
  A Mern-stack web application designed to help students organize their studies, manage academic tasks and plan their study schedules       efficiently.

## Purpose
  The Smart Study Planner was developed to provide students with a centralized platform for organizing their academic activities and        managing their study time effectively.

Features
  1) User Registration and Login
  2) Subject Management
  3) Task Management
  4) Study Timetable
  5) Study Progress Tracking
  6) Study Suggestions
  7) User Settings
  8) Responsive User Interface

Technologies Used
  Frontend:- React.js
             HTML5
             CSS3
             JavaScript
             Material UI
  Backend:- Node.js
            Express.js 
  Database:- MongoDB
  Tools:- Git
          GitHub
          Visual Studio Code

Installation
  1) Clone the repository.
       git clone https://github.com/Tharukshi-hub/Study-Planner.git
  2) Navigate to the project.
       cd Study-Planner
  3) Install frontend dependencies
       npm install
  4) Start the frontend.
       npm start
  The frontend will run at http://localhost:3000

Backend setup
  1)Install the backend dependencies.
        npm install
  2) Start the backend server:
        npm start
